# BPFCo Presence — ELINO Harvest

Source:
https://github.com/Tacky7788/Project-elino

License:
MIT

Purpose:
Selected ELINO presentation components are being used as building blocks for
the BPFCo Presence layer.

Harvested:
- VRM renderer
- Live2D renderer
- character control
- docked character UI
- VR overlay
- lip sync
- motion/animation
- TTS adapter
- STT adapter
- window/data/web bridge components
- renderer types/styles

Deliberately NOT harvested into the BPFCo runtime:
- ELINO brain
- LLM provider
- prompt builders
- memory/vector system
- ELINO-specific reasoning/orchestration

BPFCoBrain remains authoritative.

Dependency policy:
No npm/node_modules were installed.
This is source harvesting only.
Heavy dependencies remain Wi-Fi-only.
