# BPFCoBrain

A structured knowledge lattice built with Obsidian, Graphfy, and Claude for token-efficient context management.

## Structure

- `00-Inbox` — Quick captures
- `01-Concepts` — Core ideas & definitions
- `02-Projects` — Active work
- `03-References` — External sources
- `04-Fleeting-Notes` — Temporary thoughts
- `05-Atomic` — Single-idea notes
- `06-Maps-of-Content` — Hub/lattice nodes

## Tools

- **Obsidian** — Knowledge base & bidirectional linking
- **Graphfy** — Graph visualization of connections
- **Claude** — AI-powered context extraction via indexer
- **OmniRoute** — Orchestration & workflow automation

## Getting Started

1. Open vault in Obsidian
2. Use templates from `/Templates` folder
3. Build interconnected notes using `[[link-syntax]]`
4. View knowledge graph in Obsidian or Graphfy
