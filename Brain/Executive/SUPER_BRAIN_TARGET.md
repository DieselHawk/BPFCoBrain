# BPFCo Super Brain Target

The long-term UI is a spatial knowledge cockpit:

Starfield
  -> BPFCo knowledge universe
  -> zoom
  -> nodes
  -> relationships
  -> documents
  -> agent context

Agent call:
  -> selected agent
  -> face-to-face presence
  -> voice-to-voice interaction
  -> shared context from BPFCoBrain

Approval:
  -> terminal approval
  -> USB hardware present
  -> cryptographic validation
  -> accept/reject
  -> external action only after successful validation

Build rule:
Use existing BPFCo systems and proven Git components.
Build adapters and integration code, not replacement implementations.
