## What Each Option Does

### [1] 🔍 Search for Concept
- Type: `graph analysis`
- Brain searches all 793 files
- Shows results + offers to get Claude context
- **Result**: Copy-paste ready context for Claude

### [2] 🔗 View Graph (Obsidian)
- Opens Obsidian automatically
- Press `Ctrl+G` to see visual graph
- Click any node to explore
- **Result**: See how everything connects

### [3] 📁 Import New Files  
- Paste file path: `C:\path\to\file.py`
- Choose category (or use default)
- Brain adds file instantly
- **Result**: New file becomes searchable

### [4] 💬 Get Claude Context
- Type concept: `clustering`
- Brain finds all related files
- Gives you formatted text
- **Result**: Copy → paste into Claude

### [5] ⚡ Check Tokens
- Shows token usage for all models
- If one model runs out → brain auto-switches
- **Result**: Know when you might need to wait

### [6] 📚 See All Notes
- Lists all 793+ notes in brain
- Shows which folder each is in
- **Result**: Browse everything available
